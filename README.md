# Bandapps

Crie um site que seja assim: no canto uma barra de ferramentas com três opções: IA, gravador e moodle. Na IA colocar para usar; Perguntas, imagem e vídeo, e o texto. As perguntas perguntar para o site https://duck.ai/, a de imagem use a ia de https://pt.vidnoz.com/ia-gerador-de-imagens-gratis.html e a de vídeo use https://loremotion.com/generate. Gravador mostre o site https://gravacaofake.lovable.app/ e moodle redirecione em uma nova aba o site https://colbandcom.sharepoint.com/Pages/Colband.aspx. Use esse logo para a página
